# 🛒 Super Market Cost

Εφαρμογή (PWA) για Android που καταγράφει τα έξοδα σούπερ μάρκετ από **φωτογραφία ή PDF απόδειξης**, με στατιστικά, μηνιαία αναφορά και αντίγραφο ασφαλείας στο Google Drive.
Δεν έχει server: τρέχει εξ ολοκλήρου στο κινητό και φιλοξενείται ως στατικό site στο Netlify.

## Λειτουργίες

**Καταχώρηση**
- 📷 **Φωτογραφία απόδειξης** – OCR (ελληνικά + αγγλικά) που διαβάζει σύνολο, ημερομηνία και ώρα. Η τιμή πάντα επιβεβαιώνεται από τον χρήστη πριν την αποθήκευση.
- 🔳 **Σάρωση QR → PDF** – διαβάζει το QR της απόδειξης (Epsilon Digital), ο χρήστης περνά το bot check και αποθηκεύει τη σελίδα ως PDF, και η εφαρμογή εισάγει έμπορο, ΑΦΜ, ΜΑΡΚ/UID, ΦΠΑ και **όλα τα προϊόντα**.
- ⌨️ **Χειροκίνητη εισαγωγή** με ποσό, ημερομηνία, ώρα, κατηγορία και σημείωση.
- Κατηγορίες: SuperMarket (προεπιλογή), MiniMarket, Βενζίνη, Κρέατα, Μανάβικο, Άλλο.
- Έλεγχος διπλοκαταχώρησης (ίδιο QR ή ΜΑΡΚ) και επεξεργασία / διαγραφή από το Ιστορικό.

**Ανάλυση**
- Σύνολα ημέρας, μήνα και έτους.
- Γραφήματα ανά εβδομάδα (12) και μήνα (12) με ένδειξη αύξησης/μείωσης, και ετήσια προβολή.
- Στατιστικά ανά κατηγορία και ανά επιχείρηση, με φίλτρο κατηγορίας.
- **Μηνιαία αναφορά**: σύγκριση με τον προηγούμενο μήνα και τον ίδιο μήνα πέρυσι, μέσο καλάθι, κορυφαίες επιχειρήσεις, συνήθειες και ποσοστό επαληθευμένων δεδομένων. Κοινοποίηση ως κείμενο ή αποθήκευση ως PDF.
- Σήμανση **✔ επαληθευμένο** για καταχωρήσεις από PDF (με ΜΑΡΚ).

**Δεδομένα**
- Αποθήκευση τοπικά (`localStorage`) και **αντίγραφο στο Google Drive** (κρυφός φάκελος της εφαρμογής, `drive.appdata`), με συγχώνευση και επαναφορά μετά από επανεγκατάσταση.
- Εξαγωγή / εισαγωγή JSON.
- Το κατάστημα «θυμάται» όνομα και κατηγορία με βάση το ΑΦΜ.

## Τεχνολογίες

| Τι | Πώς |
|---|---|
| Εφαρμογή | Vanilla HTML / CSS / JavaScript, χωρίς build |
| Εγκατάσταση | PWA (`manifest.webmanifest`, service worker) |
| OCR | [Tesseract.js](https://github.com/naptha/tesseract.js) v5 (`ell+eng`), δύο περάσματα και περιστροφή αν χρειαστεί |
| QR | `BarcodeDetector` του Chrome, με εφεδρικό [jsQR](https://github.com/cozmo/jsQR) |
| PDF | [pdf.js](https://mozilla.github.io/pdf.js/) 3.11 – ανάγνωση κειμένου με επανασύνθεση γραμμών από τις θέσεις των χαρακτήρων |
| Αντίγραφα | Google Identity Services + Drive REST API (`drive.appdata`) |
| Φιλοξενία | Netlify (static) |

## Δομή

```
site/
  index.html, style.css      Διεπαφή (μενού επάνω, σκούρο/ανοιχτό θέμα)
  app.js                     Λογική, γραφήματα, OCR, Drive
  epsilon.js                 Αναλυτής απόδειξης Epsilon Digital (κείμενο → δομή)
  sw.js, manifest.webmanifest, icon-*.png
  _headers                   Cache / COOP headers για Netlify
mkicons.js                   Παράγει τα εικονίδια PNG (node mkicons.js)
```

## Εκτέλεση και ανάπτυξη

```bash
# Τοπικά (οποιοσδήποτε στατικός server)
npx serve site

# Deploy στο Netlify
npx netlify-cli deploy --prod --dir=site
```

### Ρύθμιση Google Drive (μία φορά)
1. Στο Google Cloud Console φτιάξε project και ενεργοποίησε το **Google Drive API**.
2. OAuth consent screen → External → πρόσθεσε το email σου στους *Test users*.
3. Credentials → **OAuth client ID** τύπου *Web application*, με *Authorized JavaScript origin* το URL του site σου.
4. Βάλε το Client ID στη σταθερά `DEFAULT_CID` του `site/app.js` (ή στις Ρυθμίσεις της εφαρμογής).

> Το Client ID **δεν** είναι μυστικό, αλλά δεν χρειάζεται ποτέ το *client secret*. Μην το βάλεις στο repo.
> Όσο το project είναι σε κατάσταση *Testing*, η άδεια λήγει κάθε 7 ημέρες και ζητείται ξανά σύνδεση.

## Γνωστοί περιορισμοί

- Το OCR φωτογραφίας δεν είναι αλάθητο (τσαλακωμένες ή σκιασμένες αποδείξεις). Η τιμή επιβεβαιώνεται πάντα χειροκίνητα.
- Η εισαγωγή προϊόντων από QR → PDF έχει δοκιμαστεί μόνο με **Epsilon Digital**. Άλλοι πάροχοι μπορεί να χρειαστούν δικό τους αναλυτή.
- Η σελίδα της Epsilon προστατεύεται με Cloudflare Turnstile, γι' αυτό το bot check το περνά ο ίδιος ο χρήστης και η εφαρμογή διαβάζει το PDF που αποθηκεύει. Δεν γίνεται αυτόματη άντληση.
- Το αυτόματο αντίγραφο στο Drive βασίζεται σε σιωπηλή ανανέωση της άδειας της Google. Αν αποτύχει, η αλλαγή μένει «εκκρεμής» και ξαναδοκιμάζεται όταν ανοίξει η εφαρμογή.
- Δεν υπάρχει «Αναίρεση» μετά από διαγραφή.
